# 🚗 SlotIQ – Smart Parking Space Allocation

SlotIQ is a Python-based DAA project that uses the **Greedy Algorithm** to allocate the nearest available parking slot.

### Features
- View available and occupied parking slots.
- Allocate the nearest available slot.
- Release occupied parking slots.
- Visualize parking statistics using charts.

### Technologies Used
Python, Streamlit, Pandas, Matplotlib

### Run the Project
```bash
pip install streamlit pandas matplotlib
python -m streamlit run app.py
```
